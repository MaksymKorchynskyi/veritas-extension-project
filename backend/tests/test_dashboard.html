📋 Інструкція з тестування

  1. Переконайтесь, що бекенд запущений (uvicorn app.main:app --reload)
  2. Переконайтесь, що VERITAS розширення встановлено в Chrome
  3. Натисніть "Open" біля статті — вона відкриється у новій вкладці
  4. Натисніть іконку VERITAS у Chrome → "Analyze This Article"
  5. Запишіть Trust Score у поле біля статті
  6. Перевірте highlights, tooltip'и на сторінці
  7. Після аналізу всіх статей натисніть "Export CSV"
